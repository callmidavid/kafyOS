# Kafy Manual

This is the user-facing documentation for Kafy OS. It explains how to use Kafy without requiring familiarity with Arch Linux, Hyprland, or the terminal.

Kafy is currently an early live ISO. Its Hyprland desktop, networking, audio, application launcher, notifications, and installer entry point are under active development. Treat installation as experimental until the release notes say otherwise.
