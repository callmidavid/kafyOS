# Welcome to Kafy

Kafy is a lightweight Linux desktop based on Arch Linux and Hyprland. It is being designed around the calm, fluid feel associated with macOS while remaining simple for people who do not work in a terminal.

The first Kafy release is a foundation, not the finished desktop. It provides a fast Wayland session, a top bar, application launcher, notifications, networking, Bluetooth, audio, a file manager, Firefox, and a live installation entry point. Kafy will add its own dock, control center, settings, and guided first-run experience in later milestones.

Kafy does not ask you to learn tiling-window-manager vocabulary to get started. Open the application launcher with `Super + Space`, pick an app, and use the desktop normally. The `Super` key is usually the key with the Windows logo.

## What is included today

- Hyprland for a responsive Wayland desktop.
- A Kafy wallpaper and top bar with workspace, clock, network, Bluetooth, volume, battery, and tray indicators.
- Firefox, Thunar file manager, Foot terminal, Flatpak support, and core hardware services.
- PipeWire audio, NetworkManager networking, and Bluetooth support.
- Gaming foundations including Steam, Wine, GameMode, MangoHud, Vulkan tools, and Gamescope.

## What is still being built

- A Kafy dock and unified app/system menu.
- Graphical settings and update surfaces.
- A production-ready graphical installer and first-boot setup.
- Kafy-owned packages, signing, and a tested update channel.

Do not treat an early Kafy ISO as a replacement for important data or a production machine. Test it in a virtual machine or on a spare drive first.
