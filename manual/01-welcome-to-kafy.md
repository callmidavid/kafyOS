# Welcome to Kafy

Kafy is a lightweight Linux desktop based on Arch Linux and Hyprland. It is designed around a calm, fluid desktop while remaining simple for people who do not work in a terminal.

The Kafy session uses a native Quickshell desktop: a top bar, launcher, notification center, control center, dock, wallpaper-driven theme, and a graphical installation entry point. Kafy is currently a release candidate, not a stable public release; do not install it on important data until the release notes mark a version stable.

Kafy does not ask you to learn tiling-window-manager vocabulary to get started. Open the application launcher with `Super + Space`, pick an app, and use the desktop normally. The `Super` key is usually the key with the Windows logo.

## What is included today

- Hyprland for a responsive Wayland desktop.
- A Kafy wallpaper-driven theme, Quickshell top bar, application launcher, notifications, control center, and dock.
- Firefox, Thunar file manager, Foot terminal, Flatpak support, and core hardware services.
- PipeWire audio, NetworkManager networking, and Bluetooth support.
- Gaming foundations including Steam, Wine, GameMode, MangoHud, Vulkan tools, and Gamescope.

## Before stable release

- A signed ISO release and public verification instructions.
- Automated installation, update, and recovery acceptance coverage for each release artifact.

Do not treat an early Kafy ISO as a replacement for important data or a production machine. Test it in a virtual machine or on a spare drive first.
