# Keyboard Shortcuts

`Super` usually means the Windows-logo key.

| Shortcut | Action |
| --- | --- |
| `Super + Space` | Open the application launcher |
| `Super + Enter` | Open the terminal |
| `Super + E` | Open the file manager |
| `Super + Q` | Close the active window |
| `Super + F` | Toggle full screen |
| `Super + L` | Lock the screen |
| `Super + 1`, `2`, `3` | Switch workspace |
| `Super + Shift + 1`, `2`, `3` | Move window to workspace |
| `Super + left-drag` | Move a window |
| `Super + right-drag` | Resize a window |

These shortcuts are the current live-ISO defaults. They will be kept stable where possible, but Kafy is still in active development.
