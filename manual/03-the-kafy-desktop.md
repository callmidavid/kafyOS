# The Kafy Desktop

Kafy currently uses Hyprland. Windows are arranged automatically, but normal mouse and keyboard use remains available.

## Top bar

The top bar shows workspaces at the left, time in the center, and system status at the right. The right side includes network, Bluetooth, audio, battery where available, and the system tray.

## Opening applications

Press `Super + Space` to open the app launcher. Type the name of an application, then press Enter. This is the main way to open applications in the current desktop.

## Windows and workspaces

Kafy starts with three numbered workspaces. Press `Super + 1`, `Super + 2`, or `Super + 3` to move between them. You can move a window to one by holding `Super + Shift` with its number.

Use `Super + F` for full screen. Hold `Super` and drag with the left mouse button to move a window; hold `Super` and drag with the right mouse button to resize it.

## Connection, audio, and notifications

The live session starts NetworkManager, Bluetooth, PipeWire, and notifications automatically. If a status icon is present, use it first; Kafy's dedicated graphical control center is a future milestone.
